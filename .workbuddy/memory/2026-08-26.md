## Agent 项目初始化

在 `C:/Users/18321/Desktop/tc` 下搭建了两个独立项目：

- `agent-backend/`：Python + FastAPI。`app/agent/core.py` 是 Agent 核心（chat / chat_stream），
  `app/agent/llm.py` 用 openai SDK 连 DeepSeek 兼容接口。接口：`GET /api/health`、

  `src/components/ChatBox.vue` 是聊天界面。vite proxy 把 `/api` 转发到 127.0.0.1:8000。

要点：
- 模型名不写死，通过 `DEEPSEEK_MODEL` 配置，默认 `deepseek-chat`。用户最初提到
  "DeepSeek v4 flash"，官方无此名称，已做成可配置项待其确认。
- 本机 Python 3.13.14，后端已过语法校验，依赖尚未安装。
